# German-Aricles-and-Nouns
An exploratory data analysis of 10,000 German nouns using PostgreSQL and AWS RDS. Investigates grammatical gender patterns, noun endings, and their predictive associations through SQL queries, statistical analysis, and an interactive Power BI dashboard. Includes data cleaning, methodology, visualizations, and comparisons with linguistic studies.


Dataset Information & Licensing

Original Data Source

This dataset is derived from german-nouns, maintained by gambolputty and compiled from German Wiktionary.

Original repository: https://github.com/gambolputty/german-nouns

Original contributors: Wiktionary contributors and gambolputty.

Original license: CC BY-SA 4.0.

Modifications

The original dataset was processed for an independent statistical analysis.

Modifications include:

Data cleaning and filtering.

Mapping grammatical gender codes (m, f, n) to definite articles (der, die, das).

Selection of a random sample of 10,000 German nouns.

Preparation of the dataset for statistical analysis.
